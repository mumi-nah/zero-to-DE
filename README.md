# zero-to-DE
This repository documents my learning journey through Data Engineering. As I pick up new tools, concepts, and methods, I create a dedicated directory for each one and document what I've learned, the goal being to reinforce understanding, track progress, and build a reference I can always come back to.

## Why This Exists
The best way I know how to solidify something I've learned is to write about it. This repo is that space. It's not a course, not a tutorial series, just an honest, ongoing record of my learning process, written in my own words as I go.

## Structure
Each directory in this repo maps to a tool, concept, or method I've explored. Inside, you'll find notes, breakdowns, and anything else that helped me understand it.
